# order_tracker
Order Tracker
_____________

A responsive web-based Order Tracker and Restaurant Ordering System designed to simplify the process of browsing restaurants, managing food items, placing orders, and tracking order details.

The project provides separate interfaces for customers and restaurant owners. Customers can explore available restaurants, view menus, add items to their cart, and review their orders. Restaurant owners can manage their menu items and keep track of incoming orders.

Features
_________

- 🍽️ Restaurant browsing and selection
- 🔎 Restaurant search functionality
- 📋 Dynamic menu and food item management
- 🛒 Shopping cart with item and price tracking
- 📦 Order tracking interface
- 👨‍🍳 Separate customer and restaurant-owner interfaces
- 💾 LocalStorage-based data persistence
- 📱 Responsive and user-friendly UI
- 🔗 Multiple pages connected into a complete ordering workflow

Tech Stack
___________

- HTML5 — Structure and page layout
- CSS3 — Styling, positioning, responsiveness, and UI design
- JavaScript — Dynamic functionality, DOM manipulation, search, cart management, and LocalStorage

Project Purpose
_______________

This project was built as a hands-on web development project to understand how multiple webpages can work together as a single application and to gain practical experience with JavaScript, DOM manipulation, LocalStorage, and frontend development.
